# إمبراطورية بائع الكون (Kon Empire) v3

لعبة Idle/Tycoon بمنظور 2.5D. JavaScript خام (ES Modules) بلا Build ولا مكتبات. موقع ثابت على Vercel.

## النشر
ارفع كل الملفات في جذر المستودع (بدون مجلدات، ما عدا tests/ الاختياري) وVercel يعيد النشر تلقائيًا.
احذف game.js القديم من المستودع إن وُجد.

## البنية
- data.js: الجداول (المباني، المناطق، السلّم، التقنيات، الشجرة). الضبط هنا.
- state.js: الحالة والحفظ (إصدارات، ترحيل v2، نسخة احتياطية، تصدير/استيراد، تعقيم).
- economy.js: الحسابات والإجراءات (بلا DOM وقابلة للاختبار في Node).
- engine.js: حلقة المنطق، الغياب، الشهب، الأحداث، الحفظ، حماية النقر الآلي.
- missions.js: مهام إرشادية (هي الـ Tutorial)، يومي/أسبوعي، دخول 7 أيام، إنجازات.
- render.js: رسم Canvas. ui.js وpanels.js وuicore.js: الواجهة. audio.js: صوت برمجي بلا ملفات.
- ads.js: Ads.rewarded(placement). الوضع الافتراضي mock (عدّاد 5 ثوانٍ). للإيقاف: config.mode = "off". لربط مزوّد: Ads.register({isReady, show}).
- analytics.js: addProvider((name, props) => ...) لربط أي خدمة.
- sw.js + manifest.webmanifest: PWA (الشبكة أولًا فلا تعلق التحديثات).

## الاختبارات
- node tests/logic.mjs: الحفظ التالف، الترحيل، الاستغلال، الأرقام الشاذة، الأداء.
- node tests/sim.mjs: محاكاة الاقتصاد (نشط/عادي/كسول).
- python3 tests/smoke.py و flow.py: اختبار المتصفح (Playwright + python3 -m http.server 8765).

## حدود معروفة
- لا خادم: تغيير ساعة الهاتف يمكن استغلاله جزئيًا (المكافآت اليومية والغياب). الحماية: الساعة لا ترجع للخلف وسقف للغياب.
- تعديل localStorage يدويًا ممكن (الحفظ يُعقَّم ويُفحص بتجزئة لكنه ليس تشفيرًا).
